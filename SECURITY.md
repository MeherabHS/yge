# Security policy

Please report vulnerabilities privately to `youthforagreenearth@gmail.com`. Do not include credentials or personal data in a public GitHub issue.

Include the affected route, reproduction steps, impact, and any suggested mitigation. The maintainers will acknowledge a complete report as soon as practical and coordinate remediation before public disclosure.

Only the latest commit on `main` is supported. Production credentials must remain in the deployment provider's encrypted environment settings and must never be committed.
